# l3bins archive

`l3bins.md` is an ASCII Markdown copy of NASA OBPG's page "Integerized
Sinusoidal Binning Scheme for Level 3 Data", taken from the Wayback Machine
capture of 6 Jan 2026 (saved as MHTML by Michael Sumner, 7 Oct 2026).
Provenance and the list of changes are in the comment at the top of the file.

`images/` holds the page's figures as saved: the thumbnail versions of
figures 1 to 5 (the full-size versions were not in the saved page; the
Markdown links to them on the original site) and the Figure 6 MODIS image
and overlays.

Home: embedded in the hypertidy/L3bin package under `inst/l3bins/`, with the
DESCRIPTION URL and the main README pointing to the Wayback snapshot. The raw
MHTML capture is kept alongside as `l3bins.wayback-20260106.mhtml`.
